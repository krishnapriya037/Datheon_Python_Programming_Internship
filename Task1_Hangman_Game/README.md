# Task 1: Hangman Game

A Python-based word guessing game developed for the Datheon Python Programming Internship.

## Features

* Random word selection
* ASCII hangman graphics
* Letter guessing
* Input validation
* Duplicate guess prevention
* Win and lose conditions
* Replay option

## Technologies Used

* Python
* Random module
* OS module

## How to Run

Make sure `hangman.py` and `words.txt` are in the same folder.

Run the following command:

```bash
python hangman.py
```
